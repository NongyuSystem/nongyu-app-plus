# 调试链路走命令行 + 蓝叠，不追 IDE 集成

本机只装了 IntelliJ IDEA 2025.3.2（Android 插件未装、基座仅支持到 AGP 8.12），而工程用 AGP 9.2.1；官方唯一支持该 AGP 的 IDE 是 Android Studio Quail 1（2026.1.1）。为了让「改完代码能在电脑上看到界面并打断点」尽快可用、且不改动已验证可构建的工具链，决定**不降 AGP、不装 Android Studio、不追 IDE 内 Run**，改用命令行链路：ADB 连蓝叠 Tiramisu64（API 33）→ `gradlew :app:installDebug` → `am start` → `adb logcat`，断点走 IDEA Remote JVM Debug。

## Status

accepted（2026-11-06，维护者在 wayfinder #9 拍板选 C）

## Considered Options

| 选项 | 否决理由 |
| --- | --- |
| **A 降 AGP 到 8.12** | 要改 7 处构建/文档文件 + 降 Gradle + 加回 `kotlin-android` 插件 + 装 2 个 IDEA 插件；现有依赖的 AAR 元数据最高要求 AGP 8.9.1 + compileSdk 36，而 AGP 8.12 最高 API 就是 36，贴天花板零余量；与「未来解锁 MeshGradient（需 compileSdk 37）」直接冲突；且「装插件后 sync 真能过」无一手证据。详见 `docs/research/agp-downgrade-impact.md`。 |
| **B 装 Android Studio Quail 1（2026.1.1）** | 官方唯一确定性方案，功能最全（Run/断点/Preview/Layout Inspector/Logcat）。但需 2–3 GB 安装，且维护者明确不想为此装一个 AS；本工程当前只需要「看界面 + 打断点」，C 已覆盖。保留为**以后需要 `@Preview` 或 Layout Inspector 时的升级路径**。 |
| **D 等 IDEA 2026.3 + 插件 263.7307.200** | 跨 build 强装被 `since/until-build` 硬挡，官方无 model-only 分发物；JetBrains 回复「只能等 tooling 合进 IDEA」。不是当前可操作项。 |

另有一条被事实核查判死的路：**不降 AGP 直接让当前 IDEA sync**。见 `docs/research/agp9-ide-sync-without-downgrade.md` —— `android.newDsl=false` 改的是 DSL 实现类，而 IDEA sync 读的是 Gradle Tooling API 的 `AndroidProject` 模型（真实报错 `Unsupported method: AndroidArtifact.getPrivacySandboxSdkInfo()` 属模型层），不同层；`gradle.ide.support.future.agp.versions` 官方支持帖里提问者照做仍报同样错。

## Consequences

- **`@Preview` 在 IDE 里不可用**（渲染器随未安装的 Android 插件走）。静态界面图可用 `com.android.compose.screenshot` 的 Gradle 截图任务补充，但那是非实时 PNG，且 AGP 9.2.1 兼容性未实测。
- **改一行代码要看界面需执行一条命令**，故需要一个 `run.ps1` 把「编译 + 装 + 起 + 抓日志」压成一步；该脚本的落地属于 #7，不在本决策内。
- **蓝叠只能评方向、不能定手感**：`enable_vsync=0` + `max_fps=60` + 鼠标输入，帧节奏不对齐真机。**长按手感/帧率的定稿必须回 USB 真机**（见 `docs/research/bluestacks-adb-compose.md`）。
- 本决策**不改动任何构建文件**：AGP 9.2.1 / Gradle 9.4.1 / Kotlin 2.3.0 / Compose BOM 2025.12.00 / compileSdk 36 全部保持不动，已验证可构建的基线不受影响。
- 未来若要 IDE 内 Run 或 `@Preview`，走 B 升级，不回头选 A。
