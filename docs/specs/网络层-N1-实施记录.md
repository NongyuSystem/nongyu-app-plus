## 3 踩到的坑

### 3.1 Kotlin 块注释会嵌套 —— KDoc 里写 `/school/*` 会编译失败

```
e: SessionInvalidListener.kt:23:1 Syntax error: Unclosed comment.
```

Kotlin 的 `/* */` **支持嵌套**（与 Java 不同）。在 KDoc 里写路径通配符 `/school/*` 时，其中的 `/*` 会被当成新开一层注释，导致整份文件注释未闭合。

**修法**：写成 `/school/` 或转义成 `/school/\\*`。已在本分片修正，后续分片写 KDoc 时注意。

### 3.2 干净 `GRADLE_USER_HOME` 没有 wrapper 发行版

用 `gradlew.bat` + 干净 home 会去 `services.gradle.org` 下载 9.4.1 发行版并**超时**（本机网络）。

**修法**（`docs/testing.md` 已记录）：直接调已解压的
`C:\Users\LENOVO\.gradle\wrapper\dists\gradle-9.4.1-bin\arn2x92ynaizyzdaamcbpbhtj\gradle-9.4.1\bin\gradle.bat`。
绕开 wrapper 的下载校验。
