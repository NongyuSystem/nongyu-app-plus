## 3 踩到的坑

### 3.1 `android.util.Log` 在纯 JVM 单测里是 stub（与 `org.json` 同类）

```
java.lang.RuntimeException: Method d in android.util.Log not mocked.
```

直接后果：**失效判据、重试判定、会话清理**这些最该测的逻辑全部无法在纯 JVM 验证。

**修法**：抽 `net/core/NongyuLogger` 接缝。纯逻辑层只依赖接口，Android 实现放 `net/http/AndroidLogger`。
测试传收集器，还能顺带断言「日志里不含明文」。

**被否掉的**：在 `build.gradle.kts` 里开 `testOptions.unitTests.isReturnDefaultValues = true`。
那只是让 stub 返回默认值、把断言变成空转，与「用真值验证脱敏」的目标相反。

### 3.2 Kotlin 块注释嵌套（**本次会话第 3 次踩**）

`ApiErrorCode.kt` 里写 `` `internal/identity/**` ``、`SchoolApi.kt` 里写 `` `/school/*` ``，都触发
`Syntax error: Unclosed comment`，且报错行号指向文件末尾。

**已写入仓库 `AGENTS.md` 作为硬规则**（见 §5），不再依赖记忆。

### 3.3 `fun interface` 不能有两个抽象方法

初版 `NongyuLogger` 写成 `fun interface` 却声明了 `log` + 两个助手方法，Kotlin 直接拒绝。改为普通 `interface` + `companion object` 里的 `Noop` / `of(...)`。

### 3.4 依赖注入不全导致「测试静默空转」

`OkHttpFactory.build()` 初版不接受 `logger` 参数，拦截器内部用默认 `Noop`。
测试断言「日志里应有 `***`」失败 —— 实际是**日志根本没输出**，而不是脱敏没生效。

**教训**：断言「不包含 X」时，必须同时断言「包含 Y」证明日志链真的在跑。

## 5 已写入 `AGENTS.md` 的硬规则

```markdown
## Kotlin 代码规则

- **KDoc / 块注释里不得出现 `/*`**。Kotlin 的块注释**支持嵌套**（Java 不支持），
  KDoc 里写路径通配（`/school/*`、`src/**/*.kt`）或任何含 `/*` 的文本，
  都会新开一层注释并报 `Syntax error: Unclosed comment`，
  且**报错行号指向文件末尾**，与真正的元凶相隔很远。
  写法：改写成 `/school/` 或改用 `//` 行注释。
```
